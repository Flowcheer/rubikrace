# Rubik's Race in Raylib
This project is a recreation of the Rubik's Race board game in C++ using Raylib.

# Setup
- go to the `build` directory
- run `./premake5 gmake`

# Build
- go back to root directory
- run `make`
- executable is in `bin` directory, run it
